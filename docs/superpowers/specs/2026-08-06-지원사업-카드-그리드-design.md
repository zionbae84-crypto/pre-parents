# 지원사업 카드 목록 UI 개선 — 설계서

## 배경 및 목적

`/guide/[stage]`, `/programs`, 검색 결과(`ResultList`) 세 화면 모두 지원사업을 한 줄짜리 풀폭 카드로 세로로 나열하고 있다. 카드 안 여백(`p-6`)이 넓어 카드 높이가 크고, 화면 오른쪽에 빈 공간이 많이 남는다. 또한 기관(정부/광역/기초)이 섞여 나열되어 있어 사용자가 "이건 국가 사업인지 우리 동네 사업인지"를 한눈에 구분하기 어렵다.

## 변경 범위

`/guide/[stage]`, `/programs`, 검색 결과(`ResultList`) 3곳의 카드 목록 렌더링. 상세 페이지(`/programs/[id]`)의 `Card` 사용은 영향받지 않는다.

## 중복 제거: 공통 컴포넌트 추출

현재 3곳에 동일한 카드 마크업(뱃지 + 카테고리 + 제목 + 요약 + "자세히 보기" 링크)이 복사돼 있다. 이번 변경에서 하나로 합친다.

- `components/programs/ProgramCard.tsx` — 지원사업 카드 하나. `program: SupportProgram`과 선택적 `showEligibilityWarning?: boolean`(기본 `false`)을 받는다. `showEligibilityWarning`이 `true`이고 `needsEligibilityCheck(program)`이 참일 때만 "⚠️ 세부조건 확인 필요" 뱃지를 표시한다(현재 `ResultList`에만 있는 동작이므로, 이 플래그로 페이지별 차이를 유지한다).
- `lib/groupByAgency.ts` — `groupProgramsByAgency(programs: SupportProgram[]): { agencyType: AgencyType; programs: SupportProgram[] }[]` 순수 함수. 정부→광역→기초 순으로, 프로그램이 있는 그룹만 반환한다.
- `components/programs/ProgramGroupedGrid.tsx` — `programs: SupportProgram[]`와 선택적 `showEligibilityWarning?: boolean`을 받아 `groupProgramsByAgency`로 나눈 뒤, 그룹마다 섹션 제목("정부 지원사업" / "광역 지원사업" / "기초 지원사업")과 2열 그리드의 `ProgramCard`들을 렌더링한다. `programs`가 비어 있으면 기존 각 페이지의 빈 상태 문구를 그대로 쓸 수 있도록, 빈 배열일 때는 아무것도 렌더링하지 않는다(빈 상태 메시지는 호출부에서 그대로 유지).

세 페이지는 기존의 카드 반복 렌더링 블록을 `<ProgramGroupedGrid programs={...} />` 호출로 교체한다. `ResultList`만 `showEligibilityWarning`을 `true`로 넘긴다.

## 레이아웃

- 섹션 제목: `font-display text-[19px] text-brown`, 그룹 사이 `mt-8` 간격
- 그리드: `grid grid-cols-1 sm:grid-cols-2 gap-4` (좁은 화면 1열, 그 이상 2열)
- 카드 패딩 축소: `components/ui/Card.tsx`에 `compact?: boolean` prop을 추가해 `true`일 때 `p-4`(기존 `p-6` 대신)를 쓴다. 기존 5곳(상세 페이지)은 `compact` 없이 그대로 `p-6` 유지. `ProgramCard`는 `compact` 카드를 사용하고, 뱃지-제목 사이 여백도 `mb-2`→`mb-1.5`로 살짝 줄인다.

## 데이터 흐름 예시

`/programs`에서 "기관: 기초"로 필터링하면 `filtered` 배열에는 `agencyType: '기초'`인 항목만 남고, `groupProgramsByAgency`는 `[{ agencyType: '기초', programs: [...] }]` 하나만 반환하므로 "기초 지원사업" 섹션 하나만 2열 그리드로 표시된다. 필터를 걷어내면 다시 정부/광역/기초 최대 3개 섹션이 순서대로 표시된다.

## 테스트 방침

`groupProgramsByAgency`는 순수 함수이므로 `lib/groupByAgency.test.ts`에서 유닛 테스트한다(빈 배열, 한 기관만 있는 경우, 세 기관이 섞인 경우의 순서·그룹핑). `ProgramCard`/`ProgramGroupedGrid`는 UI 컴포넌트라 기존 프로젝트 방침대로 자동화 테스트 없이 브라우저로 수동 검증한다(3개 페이지 각각에서 2열 그리드·섹션 제목·패딩 축소·`ResultList`의 경고 뱃지 노출 여부 확인).
