# 예비부모 정부지원금 통합 플랫폼 — 설계서

## 배경 및 목적

출산예정/영유아 양육 예비부모를 위한 정부지원 제도는 정부, 광역지자체(시/도), 기초지자체(시/군/구) 단위로 각각 공고되어 정보가 산발적으로 흩어져 있다. 예비부모가 자신에게 해당하는 지원사업을 한 곳에서 확인하기 어렵다.

이 플랫폼은 임신 준비부터 유아기까지 단계별로 어떤 제도가 있는지 소개하고, 거주지/나이/소득수준을 입력하면 맞춤형으로 해당 지원사업을 찾아주는 웹앱을 제공한다.

## MVP 산출물

실제 동작하는 Next.js + TypeScript 웹앱. 로그인 없이 즉시 검색 가능한 형태로 배포한다(Vercel).

## 비주얼 컨셉

첨부된 Duolingo 스타일 가이드(`DESIGN (3).md`)의 **구조적 특징**을 차용하되 색상은 예비부모를 배려하는 따뜻한 톤으로 재구성한다.

- 차용하는 구조: 12~16px 라운드 모서리, 2px 보더의 "스티커" 스타일 버튼/카드, 큼직한 라운드 디스플레이 헤딩, 일러스트+텍스트 좌우 배치 섹션, 넉넉한 섹션 간 여백(80~120px)
- 색상 재정의:
  - 주 포인트(CTA/헤딩): 코랄/피치 `#FF8A65` 계열
  - 배경: 크림/아이보리 `#FFF8F0` 계열
  - 보조 포인트: 세이지 그린 `#8FBC8F` 계열, 소프트 옐로우
  - 본문 텍스트: 진한 브라운/차콜 `#5C4A3D` 계열
- 타이포: 라운드 계열 한글 지원 서체(Pretendard 등)로 feather의 통통한 디스플레이 느낌 대체
- 일러스트: 마스코트 대신 임신/육아 단계를 상징하는 부드러운 라인 일러스트
- 기관 뱃지: 정부(파랑) / 광역(코랄) / 기초(옐로우)로 주관기관 레벨을 색상 구분

## 화면 구성 (IA)

1. **랜딩**: 서비스 소개 + "맞춤 지원금 찾기" CTA + 5단계 타임라인 진입점
2. **단계별 제도 소개** (`/guide/[stage]`): 5단계 각각에 대해 정부/지자체 제도를 카테고리로 소개하는 정적 콘텐츠
3. **맞춤 검색** (`/search`): 거주지/임신·자녀상태/부모나이/가구원수/가구소득 입력 폼 + 매칭 결과
4. **검색 결과/상세**: 카드 리스트(사업명, 기관 뱃지, 요약, 신청가능여부) → 클릭 시 상세(대상, 지원내용, 신청방법/기한, 필요서류, 공식링크)
5. **전체 지원사업 목록** (`/programs`): 맞춤검색 없이 단계/기관/카테고리로 필터링해 둘러보는 브라우징 페이지

### 단계 구분 (5단계)
임신준비 → 임신중 → 출생/출산 → 영유아기(0~1세) → 유아(2세~)

## 데이터 모델

```ts
type AgencyType = '정부' | '광역' | '기초';
type Stage = '임신준비' | '임신중' | '출생출산' | '영유아기' | '유아';
type Category = '현금지원' | '바우처' | '의료비' | '돌봄서비스' | '주거' | '세제혜택' | '기타';

interface SupportProgram {
  id: string;
  title: string;
  agencyType: AgencyType;
  agencyName: string;               // "보건복지부" / "서울특별시" / "강남구"
  region: 'nationwide' | { sido: string; sigungu?: string };
  stages: Stage[];
  category: Category;
  summary: string;
  benefit: string;
  eligibility: {
    parentAgeMin?: number;
    parentAgeMax?: number;
    childAgeMonthsMin?: number;
    childAgeMonthsMax?: number;
    incomePercentMax?: number;      // 기준중위소득 몇 % 이하까지 대상
    note?: string;                  // 구조화 불가능한 예외조건 텍스트
  };
  applicationMethod: string;
  applicationPeriod: string;
  requiredDocuments?: string[];
  officialLink: string;
  lastVerifiedAt: string;
}
```

지역 목록은 별도 관리한다.

```ts
interface RegionEntry {
  sido: string;
  sigungus: string[];
}
```

기준중위소득 환산표(`median-income.ts`)는 연도·가구원수별 금액을 보관하고, `가구월소득 ÷ 해당 가구원수 기준중위소득 × 100`으로 % 를 계산한다.

## 맞춤 검색 로직

**입력 필드**: 거주지(시/도 → 시/군/구, `regions.ts` 기반 동적 렌더링), 임신/출산 상태(준비중 / 출산예정일 / 자녀 생년월일), 부모 나이, 가구원수, 가구월소득

**단계 자동 판별**
- 임신 준비 중 → `임신준비`
- 출산예정일 입력 → 오늘 기준 임신 주수 계산 → `임신중`
- 자녀 생년월일 입력 → 개월수 계산 → 0개월: `출생출산`+`영유아기`, 1~11개월: `영유아기`, 12개월 이상: `유아`

**매칭 규칙** (모두 만족해야 노출)
1. 지역: `region === 'nationwide'` 이거나, 사용자의 시/도와 일치하고 (`sigungu` 미지정이거나 사용자의 시/군/구와 일치)
2. 단계: 사용자의 현재 단계가 `program.stages`에 포함
3. 부모 나이: 지정된 범위 내(미지정 시 통과)
4. 자녀 개월수: 지정된 범위 내(미지정 시 통과)
5. 소득: 사용자의 기준중위소득%가 `incomePercentMax` 이하(미지정 시 소득무관으로 통과)

**정렬**: 정부 → 광역 → 기초 순으로 그룹핑

**애매한 조건**: `eligibility.note`에만 조건이 있는 경우 노출하되 "⚠️ 세부조건 확인 필요" 뱃지 표시, 공식 링크로 확인 유도

## 기술 아키텍처

**데이터 저장**: 로컬 구조화 데이터 파일(TypeScript)로 시작. DB/서버 인프라 없이 Next.js만으로 MVP를 완성하고, 이후 공공데이터포털/복지로 API 연동 시 데이터 계층만 교체 가능하도록 필터링 로직과 데이터 소스를 분리한다.

**지역 확장성**: 거주지 검색 폼과 `SupportProgram.region`은 처음부터 `regions.ts`의 지역 목록을 순회하는 구조로 만들어, 서울 외 지역(경기도 등) 추가 시 폼/매칭 로직 변경 없이 데이터 추가만으로 확장 가능. 데이터가 없는 지역을 선택하면 "아직 이 지역 데이터는 준비 중" 안내와 함께 전국 공통(`nationwide`) 사업만 노출한다.

**프로젝트 구조**
```
/app
  /page.tsx                    # 랜딩
  /guide/[stage]/page.tsx      # 단계별 제도 소개
  /search/page.tsx             # 맞춤 검색 폼 + 결과
  /programs/page.tsx           # 전체 목록 브라우징
  /programs/[id]/page.tsx      # 상세
/components
  /ui/                         # 버튼, 카드, 뱃지 등 디자인시스템 컴포넌트
  /search/                     # 검색 폼, 결과 리스트
/lib
  /data/
    programs.ts                # 지원사업 데이터
    regions.ts                 # 지역 목록
    median-income.ts           # 기준중위소득 표
  /matching.ts                 # 매칭 필터링 로직 (순수 함수, 데이터 소스 비의존)
  /stage.ts                    # 자녀나이/임신여부 → 단계 판별 로직
```

**배포**: Vercel

## MVP 범위

**포함**
- 랜딩 페이지 (따뜻한 컨셉 디자인)
- 단계별(5단계) 제도 소개 정적 페이지
- 맞춤 검색 폼 + 매칭 결과 리스트/상세
- 전체 지원사업 브라우징 페이지 (단계/기관/카테고리 필터)
- 초기 데이터셋: 정부 공통 사업 + 서울시 + 서울 25개 자치구 주요 사업 (수동 큐레이션, 약 30~50건 목표)
- 지역 확장 가능한 데이터/폼 구조 (서울 외 지역은 구조만 준비, 데이터는 미입력)

**제외 (추후 확장)**
- 회원가입/로그인, 북마크/저장
- 공공데이터 API 실시간 연동
- 서울 외 지역 실데이터
- 알림/리마인더 기능
- 관리자 페이지 (데이터는 코드로 직접 관리)

## 테스트 방침

- `lib/matching.ts`, `lib/stage.ts` 등 순수 로직 함수는 유닛 테스트(Vitest)로 검증 (소득 경계값, 단계 판별 경계값, 지역 매칭 케이스)
- 데이터 파일은 스키마 검증 스크립트(zod 등)로 필수 필드 누락/오타 체크
- UI는 브라우저로 주요 플로우(검색 폼 입력 → 결과 확인 → 상세 진입) 수동 확인
