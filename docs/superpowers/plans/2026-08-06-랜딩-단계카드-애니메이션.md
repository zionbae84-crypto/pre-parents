# 랜딩페이지 단계 카드 UI 개선 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 랜딩페이지의 5단계 카드에 서수 라벨과 "행복한 가정" 라인아트 아이콘을 추가하고, 아이콘이 살짝 떠오르는 애니메이션을 적용한다.

**Architecture:** 순수 CSS `@keyframes`로 애니메이션을 구현하고(외부 애니메이션 라이브러리 없음), 5개 단계별 SVG 라인아트를 하나의 `StageIcon` 컴포넌트로 만들어 기존 `app/page.tsx`의 `STAGES` 배열/카드 렌더링에 연결한다.

**Tech Stack:** Next.js(App Router) · TypeScript · Tailwind CSS v4(커스텀 CSS 키프레임 병행)

## Global Constraints

- 외부 아이콘 라이브러리, 애니메이션 라이브러리, 이미지 파일 의존성 추가 금지 — 코드로 그린 인라인 SVG + 순수 CSS 애니메이션만 사용
- 모든 사용자 노출 텍스트는 한국어
- `prefers-reduced-motion: reduce` 사용자에게는 애니메이션을 끈다
- 기존 카드의 hover 시 코랄 강조 효과(테두리·텍스트 색 전환)는 그대로 유지
- 자동화 테스트 대상 아님(순수 시각적 변경) — `npm run build`로 컴파일 확인 후 브라우저 수동 검증

**Interfaces:**
- Produces: `.animate-float` CSS 유틸리티 클래스 — Task 3에서 아이콘에 적용

- [ ] **Step 1: `app/globals.css` 끝에 키프레임과 유틸리티 클래스 추가**

`app/globals.css`의 기존 `body { ... }` 블록 뒤에 아래를 추가한다:

```css
@keyframes float {
  0%,
  100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-6px);
  }
}

.animate-float {
  animation: float 3s ease-in-out infinite;
}

@media (prefers-reduced-motion: reduce) {
  .animate-float {
    animation: none;
  }
}
```

- [ ] **Step 1: `app/page.tsx`의 `STAGES` 배열과 카드 섹션을 아래로 교체**

`app/page.tsx` 상단의 import와 `STAGES` 선언부:

```tsx
import { Button } from "@/components/ui/Button";
import { StageIcon } from "@/components/ui/StageIcon";

const STAGES = [
  { slug: "임신준비", ordinal: "첫 단계", label: "임신준비 단계" },
  { slug: "임신중", ordinal: "두번째 단계", label: "임신중 단계" },
  { slug: "출생출산", ordinal: "세번째 단계", label: "출생·출산 단계" },
  { slug: "영유아기", ordinal: "네번째 단계", label: "영유아기 단계" },
  { slug: "유아", ordinal: "다섯번째 단계", label: "유아 단계" },
] as const;
```

`app/page.tsx`의 5단계 카드 `<div className="mt-8 grid ...">` 블록 전체를 아래로 교체:

```tsx
<div className="mt-8 grid grid-cols-2 gap-4 sm:grid-cols-5">
  {STAGES.map((stage, index) => (
    <a
      key={stage.slug}
      href={`/guide/${stage.slug}`}
      className="flex flex-col items-center gap-2 rounded-card border-2 border-brown/10 bg-white p-6 text-center text-brown transition-colors hover:border-coral hover:text-coral"
    >
      <StageIcon
        stage={stage.slug}
        className="animate-float"
        style={{ animationDelay: `${index * -0.4}s` }}
      />
      <span className="text-[13px] text-brown/60">{stage.ordinal}</span>
      <span className="font-bold">{stage.label}</span>
    </a>
  ))}
</div>
```
